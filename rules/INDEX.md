# Litigation rules index

Rules are assembled from two active, append-only revision streams:

1. `GLOBAL.md` applies to every model and has authority over every model section.
2. The matching model section adds provider-specific working guidance.

| Scope | Applies to |
| --- | --- |
| Global | Every model and every handoff |
| Claude | Claude subscription agents |
| OpenAI | Codex, GPT, and Astra agents |
| GLM | GLM subscription agents |
| Gemini | Gemini and Antigravity agents |
| Cline | Cline subscription agents |
| Grok | Grok subscription agents |

Published revisions cannot be edited or deleted. Models may submit evidence-linked
proposals for their own section. A person must accept a proposal before it becomes
active. Model rules cannot expand permissions or override the global rules.
